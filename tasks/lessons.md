# Lessons

Format: `[date] | what went wrong | rule to prevent it`

2026-06-24 | Vault screen contract said `onNavigate(Dest.VaultThread(conversationId))` but Dest.VaultThread is a `data object` (not invocable with an id); a generic `(Dest)->Unit` cannot carry a route arg. | For parameterized nav with a fixed `(Dest)->Unit` screen signature, add a dedicated `onOpenThread:(Long)->Unit = {}` param (keeps the 3 mandated params intact) and document that the NavGraph wires it via `Dest.VaultThread.createRoute(id)`. Don't try to overload the generic Dest callback.
2026-06-24 | Material `Icons.Filled.Search/Close/ArrowBack` are in material-icons-CORE (bundled with material3), not material-icons-EXTENDED; greps of the extended AAR show them MISSING. | When verifying icon existence, check BOTH the extended AAR and the core AAR before concluding an icon is unavailable.
2026-06-24 | Verifying domain Kotlin via Gradle was blocked by concurrent agents' shared-state churn (a stray `res/raw/SOUNDS_README.md` re-appearing; unresolved `Theme.Material3.DayNight.NoActionBar` parent) failing resource merge/link BEFORE Kotlin compile. | To validate pure domain logic independent of the Android resource pipeline, compile the specific .kt files + test files directly with `kotlin-compiler-embeddable` and run JUnitCore. The embeddable compiler needs these on its host -cp: kotlin-stdlib, kotlin-reflect, kotlinx-coroutines-core-jvm, trove4j, org.jetbrains:annotations — all resolvable from `~/.gradle/caches/modules-2`.
2026-06-24 | Full `:app:` build failed at `processDebugResources` (before Kotlin compile): `themes.xml` used `parent="Theme.Material3.DayNight.NoActionBar"` + attrs `colorOnPrimary/colorSecondary/colorOnSecondary`, which come from the View-based `com.google.android.material:material` lib that this Compose-only app does NOT depend on. | For a Compose-only Android app (androidx.compose.material3, no com.google.android.material), the XML window theme MUST use a framework base (`@android:style/Theme.Material.NoActionBar`, API 21+) and only framework `android:`-prefixed attrs — never `Theme.Material3.*` parents or bare Material-Components color attrs. Real theming is in Compose; the XML theme only sets window background + system bars.
2026-06-24 | `timeout`/`gtimeout` are NOT installed on this macOS; `timeout 480 ./gradlew ...` fails with "command not found". | Don't wrap gradle in the shell `timeout` binary on this machine; cap long runs via the Bash tool's own `timeout` (milliseconds) parameter instead.
2026-06-24 | `./gradlew` failed: AGP 8.7.3 requires Java 17 but the machine default `java` is JDK 11 (microsoft-11.jdk); only Homebrew `openjdk@17` is present besides 8/11. | This repo builds ONLY with JDK 17. Prefix gradle with `export JAVA_HOME=/opt/homebrew/opt/openjdk@17`. Then `./gradlew :app:compileDebugKotlin :app:testDebugUnitTest --offline` succeeds (Kotlin+KSP+Hilt+resources all clean).
2026-06-24 | Writing a literal control char (U+0001) into Kotlin source via the Write/Edit tools persisted the raw byte, and the Edit tool then could not match the line to fix it. | For non-printable char literals in source, write the escape sequence (e.g. `''`); if a literal byte slips in, fix it with a scripted regex replace (python) rather than the Edit tool.
